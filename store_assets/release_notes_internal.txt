Signed with the shared Alchemist keystore
(~/AndroidKeystores/alchemist-release.jks, alias "alchemist"), and built

KNOWN LIMITATIONS

- Alarms do NOT survive an explicit Force Stop (Settings > Apps > Force
  Stop). Android cancels every pending alarm for an app put into the
  stopped state; no app can work around this. Swiping the app away from
  Recents is fine — that path is tested and works. Reopening the app
  re-registers any enabled alarm.

- Setting an alarm to the exact current minute can schedule it for
  tomorrow. If the clock ticks into the chosen minute between picking the
  time and pressing Simpan, the "next occurrence" logic sees the time as
  already past. Pick a time at least a minute ahead when testing.

- REQUEST_IGNORE_BATTERY_OPTIMIZATIONS is declared in the manifest and has
  a handler in MainActivity, but nothing calls it and there is no button
  for it in the UI. Either wire it up or drop the permission before the
  public release — declaring an unused sensitive permission invites
  questions during review.

- Password entries are protected by the Android app sandbox and the
  unlock screen, not by encryption keyed to your PIN. CSV export writes
  passwords in PLAIN TEXT so other managers can read them; delete the
  file when you are done with it.

- Currency conversion needs a network connection the first time. Rates
  are cached afterwards, so offline use shows the last fetched rates with
  a "last updated" note.

- iOS has not been tested. Everything so far was verified on an Android
  emulator (API 36, 1080x1920). The iOS bundle identifier and icons are
  set, but no build has been run on an iOS device or simulator.

- No online features, no sync, no backup — local device only. Uninstalling
  removes all data.

Please report any crashes, visual glitches, or wrong numbers.
