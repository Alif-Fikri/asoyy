# Release notes — Beres v1.0.0

Teks di bawah ini siap tempel ke Play Console → **What's new**. Field itu
dibatasi **500 karakter per bahasa**, jadi keduanya sudah dipas-paskan dan
dihitung. Kalau menambah baris, hitung ulang dulu.

Versi panjang untuk pengumuman (sosial media, README, pengantar ke beta
tester) tidak dipakai di Play Console — kalau butuh, tulis terpisah.

---

## Catatan

- App Store Connect memberi ruang lebih longgar (4000 karakter) untuk
  "What's New in This Version", jadi teks yang sama aman dipakai di sana.
- Untuk rilis berikutnya, ganti isinya dengan perubahan nyata versi itu,
  bukan daftar fitur lagi — daftar fitur tempatnya di full description.
